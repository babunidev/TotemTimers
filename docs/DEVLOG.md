# TotemTimers — development history

**Author:** Babuni.dev

## Source-based reconstruction — 2026-10-26

A compact, draggable Shaman status interface for WoW 1.12 that reports elemental totem duration, shields and weapon imbues. TotemTimers.lua and TOC support four element timers, shield charges, Shaman imbues, missing-totem warnings, and Totemic Recall; README describes UI and commands; migration script and test exist. The interface stays close to Blizzard's visual language and only appears for Shamans; totem state, shield charges and weapon effects are grouped in one tool.
